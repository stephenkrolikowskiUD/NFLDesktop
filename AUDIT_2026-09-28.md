# NFL model and presentation audit: first pass

Scope: read-only inspection of the published Picks_Weekly CSV on September 28,
2026, plus the local v3 selection and dashboard code. No paid API requests,
engine execution, grading changes, or edits to the published ledger.

## Findings

1. **Passing rules was presented as predictive validation.** The selector assigns
   VALIDATED from estimated EV and weighted evidence thresholds. That does not
   measure whether predicted probabilities match observed outcomes on unseen
   games. The first UI pass replaces the public label with Model estimate.
   Internal method IDs and historical grades remain intact.
2. **Shortlist ranking contradicted its explanation.** The UI advertised expected
   return order but added streak, probability and sample bonuses. The shortlist
   now orders by estimated return, with weighted observations as a tie-breaker.
   The arbitrary 12-row display cap is removed.
3. **Tray book attribution could be wrong.** A published pick row stores PICK_BOOK
   and PICK_ODDS, but the tray ran the prop-board price helper on it and defaulted
   to DK. The tray now preserves the captured book and price together.
4. **Probability quality remains unresolved.** The 18 published rows span
   September 27-28 and all carry the v3 model version. Their mean estimated win
   probability is 67.68%; estimated returns range up to 39.0%. Recomputing
   p * net_payout - (1-p) reproduces every stored EV within 0.049 percentage
   points, consistent with rounding. Correct arithmetic does not validate p.
5. **Weighted evidence is not an independent sample count.** The probability
   formula uses prior-season outcomes, current-season games weighted three times,
   and a 24-observation market prior. The UI now distinguishes current-season
   games from weighted observations. These weights have not been established as
   optimal by this audit.
6. **Completed picks could appear unlocked after the player slate advanced.**
   The lock helper used the player's current matchup rather than the stored pick
   event. Picks now use their own kickoff first and reject past game dates even
   when kickoff is missing. The live preview correctly removes those old rows.

## Changes in this pass

- Replace regular-season shortlist cards, tier badges and average-return headline
  with a compact list: player, selection, captured book/price, kickoff and tray action.
- Put estimated probability, estimated return, sample and matchup assumptions in
  an expandable evidence section. Matchup adjustments are explicitly already included.
- Replace featured pick confidence adjectives with source descriptions and label
  recent line-clear counts as historical observations.
- Preserve selection thresholds, probability calculations, ledger rows and grades.

## Evidence still required

- Reconstruct forecasts using only information available before each kickoff.
  Current live sheets alone cannot establish that historical snapshot.
- Evaluate v3 separately on held-out settled games: calibration by probability
  range, Brier/log loss versus the market baseline, price ROI and uncertainty.
- Audit role changes, inactivity and low-usage prior-season appearances; a current
  roster identity alone does not make old usage representative of today's role.
- Validate integer-line push handling before supporting those lines: the current
  probability helper counts ties in its denominator while the EV formula assumes
  every non-win is a loss. This pass does not change settlement or probabilities.
- Complete navigation consolidation and remaining research/slip copy separately.
  The slip generator also retains a legacy same-game score multiplier triggered
  by a game total above 9.5; it needs a separate correlation review and should not
  be interpreted as a calculated parlay advantage.
  This is the first implementation pass, not a completed product or model audit.
